# skinheat — 第1段階（Gauss 厳密解）の結果ノート

**模型:** 相反な最近接鎖 H = −J Σ(c†_j c_{j+1}+h.c.)、ボンド損失 L_j = √κ (c_j + e^{iφ} c_{j+1})（方向性散逸、Hamiltonian は対称のまま）、両端に温度 T_L, T_R の熱リード（μ=0）。
二次形式 Lindbladian なので NESS は Lyapunov 方程式 X C + C X† = M_gᵀ で厳密に解ける（`skinheat/ness.py`、4 サイト全 Fock 空間と 1e-8 で一致: `tests/test_brute_force.py`）。
有効非エルミート Hamiltonian h_eff = h − (i/2)(M_lᵀ + M_g) → t_± = −J − (iκ/2)e^{±iφ}、一様損失 −iκ。φ=π/2 で純粋な Hatano–Nelson。

**整流の測度:** ΔT 応答 δQ_f = Q_R(T_h,T_c) − Q_R(T_c,T_c)（左を加熱して右の冷リードが受ける追加熱）、δQ_r は鏡映。
R = (|δQ_f|−|δQ_r|)/(|δQ_f|+|δQ_r|)。
※「冷リードへの総熱流」で定義すると、損失シンクへの ΔT 非依存な背景流が支配して R ∝ 1/L になる（`results/rectification.json`、誤った測度の記録として保持）。

**主結果（`results/deltaT_rectification.json`, `.png`）**
1. 鏡映対称性: φ = 0, π で R = 0（厳密）。
2. 厳密則: δQ_f/δQ_r = T_RL/T_LR = |t₋/t₊|^{2(L−1)} = exp[2(L−1)/ξ]、ξ⁻¹ = ln|t₋/t₊|。エネルギー・温度に完全に独立（三重対角 Green 関数の恒等式 G_{L,1}/G_{1,L} = Π t₋/t₊）。数値と全桁一致（`tests/test_exact_law.py`）。
   小 κ: ξ ≈ J/(κ sin φ)。
3. 帰結: L/|ξ| ≳ 3 で R > 0.99。κ=0.07, L=40 で R=0.992、順方向スループットは κ=0 比で約 50 %（δQ_f: 0.040 → 0.020）。κ を上げると R→1 だが δQ_f は損失で減衰（整流 vs スループットのトレードオフ）。
4. ボンド利得（同キラリティ）を加えても R は不変（比は t_± のみで決まる）。
5. Lyapunov 検証: リードのエントロピー生成 σ_leads = −Σ Q_α/T_α は全点で正。ただしシンク（T=0）を含む完全なエントロピー収支は未定義 → 有限温度バルク浴の定式化が次の課題。
6. メゾスコピックリード（K=80, W=4）と広帯域 Green 関数の ΔT 応答は 5–15 % で一致（帯域効果）。

**含意（論文用）**
- 自由粒子・最近接では「整流比 ↔ スキン局在長」は恒等式。非自明な物理は (a) 長距離ホッピング／多バンド（非三重対角 → 比がエネルギー依存、巻き数 w(ε) が意味を持つ）、(b) 相互作用（TEBD）、(c) 熱力学的コスト（シンクへの流出 E_bulk とエントロピー生成）にある。
- 先行研究 [485]/1806.01000（少数モード cascaded）との差別化は、「一様な相反格子＋バルク方向性散逸で、非相反比が e^{2L/ξ} と**系サイズに指数的**」という点。

**次段階**
1. 次近接ホッピング t₂ を入れて三重対角性を破り、T_RL/T_LR(ε) のエネルギー依存と w(ε) の対応を見る（Gauss で可能、即日）。
2. 相互作用 V n_j n_{j+1} を入れた TEBD（L=40–80）。
3. 有限温度バルク浴（ボンド演算子の detailed balance）とエントロピー収支の完結。

**注記（図の下段中央）:** 実エネルギー ε での巻き数 w(ε) は 0。PBC スペクトル環は中心 −iκ・虚軸半径 κ の楕円で、実軸には上端で接するだけなので、輸送エネルギー（実軸）は環の外側にある。スキン効果の位相的指標は環の重心（−iκ）まわりの巻き数（= −1、`skinheat/skin.py` の `winding_number`）であり、輸送非相反性は ξ のみで決まる。論文では w(ε) ではなく「環の存在 ⇔ ξ 有限」として記述すること。

結果:
1. **t₂≠0 で T_RL(ε)/T_LR(ε) は強くエネルギー依存**になる（t₂=0 では全桁定数）。ln 比は下側バンド端近傍で鋭いピーク（κ=0.2, t₂=0.1 で最大 35）、高エネルギー側では単調に減少し、t₂=0.3–0.5 では一部のエネルギーで比が 1 を下回る（局所的な逆整流）。
2. **熱平均した ln(δQ_f/δQ_r) は NN 則より系統的に小さい**（κ=0.2: 15.65 → 13.9 / 10.3 / 8.1）。δQ_f は t₂ とともに増加（バンド幅拡大でスループット増）、δQ_r はそれ以上に増加。R は依然 >0.97 だが「比 = exp[2(L−1)/ξ]」の恒等式は失われる。
3. **非 Bloch 則で定量的に説明できる。** 特性方程式 t₂β²+t₊β+(d−ε)+t₋β⁻¹+t₂β⁻² = 0 の根を |β₁|≤…≤|β₄| とすると
   ln[T_RL/T_LR](ε) ≃ 2(L−1) ln|β₂(ε)β₃(ε)| + O(1)
   が全 t₂・全 κ で図の点線通りに成立（NN では β₁β₂ = t₋/t₊ で定数 → 第1段階の恒等式を再現。NNN では Vieta より β₁β₂β₃β₄ = 1）。すなわち整流指数は **エネルギー分解スキン局在長 ξ(ε)⁻¹ = ln|β_pβ_{p+1}|(ε)** で、ΔT 応答比はその Fermi 窓での熱平均。
4. **巻き数との関係。** 実エネルギー ε まわりの PBC 環 h(k) の巻き数 w(ε) は t₂ によらず 0（環の Im 部は −κ(1−sin k)≤0 で実軸に接するのみ）。一様損失を引いた環 h(k)+iκ の巻き数は t₂≤0.5 では ε∈(−2J+2t₂, 2J+2t₂) で −1、外で 0 と粗い指標にとどまり、ln T 比のエネルギー依存（ピーク・符号反転）は捉えない。論文では巻き数ではなく β₂β₃(ε)（GBZ の半径比）で記述すること。

## 2b. 最近接相互作用 V n_j n_{j+1}（Lindblad MPS、`skinheat/lindblad_mps.py`, `scripts/run_beyond_nn_tebd.py`）

**手法。** 超フェルミオン（第三量子化）表現 |ρ⟩⟩ = ρ|I⟩⟩、|I⟩⟩ = Π_j(1 + c_j†c̃_j†)|0⟩。パリティ偶の ρ に対して
c_jρ → c_j, ρc_j† → −c̃_j, ρc_j → c̃_j†, ρc_i†c_j → c̃_j†c̃_i が厳密に成り立ち、Lindbladian は 2N モードの**局所**フェルミオン演算子になる
（ボンド損失 LρL† も 4 サイト内の双一次形式）。tenpy の GroupedSite(ket, bra)（局所次元 4）、保存量 N_ket−N_bra=0、
MPS 配置 [chain 0][lead L][chain 1..L−1][lead R]（長距離項の起点を鎖端に揃え MPO 次元 ≈6）、W^II MPO 伝播子（ExpMPOEvolution, order 2）。
観測量は ⟨⟨I|O|ρ⟩⟩/⟨⟨I|ρ⟩⟩。リードのジャンプ演算子は相互作用と可換なので、リード熱流は 2 点関数のみで閉じ、`skinheat.ness.energy_current` をそのまま再利用。
リードは `build_chain_with_leads` と同構成で K=10（W=4、γ=Δε=0.89）。

**検証（`tests/test_tebd_vs_gauss.py`）。** (1) 4 モード・V=0.7 で MPO Liouvillian の厳密零ベクトルが全 Fock 空間 Lindbladian の NESS と 1e-15 で一致（写像・符号・JW 列は厳密）。
(2) V=0, L=6, K=4 の時間発展 NESS が Gauss（Lyapunov）と 2e-3 以内で一致。

**精度床（必読）。** L=6,K=4,V=0 で χ∈{32,64,128,256}×dt∈{0.1,0.05,0.025}、および圧縮法 {SVD, 変分 2/4/8 sweep, zip-up} を比較（`results/beyond_nn_runs/conv/`）:
- dt=0.1 の時間刻みバイアスは電流で ~6e-5（EL）/3e-5（ER）、dt² スケール（4 モード系: dt=0.1 → 1.2e-4、0.02 → 1e-6）。SVD 圧縮と変分 4–8 sweep は同じ値に収束、変分 2 sweep は ~1e-4 の非決定的なゆらぎ、zip-up は 3e-4 のバイアス。
- L=20（N=40 サイト）では χ の打ち切りが支配的: χ=64 で Gauss との差 2–6e-3（絶対電流、4 %）、χ=128 で 1.7e-3 変化。δQ は差分なので一部相殺し、δQ_f の誤差は 4 %（L=20）/14 %（L=40, χ=64）。
- **結論: 絶対電流の床は L=20 で ~1e-3（χ=64）〜数 e-4（χ=128）。δQ_r がこれを下回る点は上限値としてのみ意味を持つ。** 解像条件は δQ_r/δQ_f = exp[−2(L−1)/ξ] ≳ 数 e-2、すなわち 2(L−1)κ/J ≲ 3–4。

**第2段階まとめ（論文用）**
- 自由粒子: 整流指数は非 Bloch 量 ln|β_pβ_{p+1}|(ε)（エネルギー分解スキン長）で決まる。NN では定数（三重対角恒等式）、NNN では ε 依存になり、ΔT 応答比はその Fermi 窓平均 → NN 則から系統的に低下するが R は依然 ≈1。
- 相互作用: exp[2(L−1)/ξ] の指数構造は V ≤ 2 で保たれ、V は L 非依存の前因子（順方向スループット低下 + 逆方向の接触寄与）を変える。κ=0.2 のような強スキン領域では MPS の精度床（絶対電流 ~1e-3）が δQ_r を覆い、上限値のみ。

# 第3段階 — 有限温度バルク浴とエントロピー収支（`results/thermal_bulk.json`, `.png`, `scripts/run_thermal_bulk.py`, `tests/test_thermal_bulk.py`）

**模型。** `build_chain_with_leads(..., bulk_bath=dict(K, W, T, mu))`: 各ボンド j に K_b モードのメゾスコピック浴（帯域 [−W_b, W_b]、(T_b, μ_b) で熱化）を付け、
ボンド演算子 A_j = c_j + e^{iφ}c_{j+1} を通して結合（v = √(κΔε/2π) → 減衰率 Γ_b = κ、第1段階の Lindblad 損失と同じ強さ）。
detailed balance は浴モードの熱化で自動的に満たされる。μ_b → −∞（空の浴）が純粋損失モデル。全リザーバが温度を持つので
σ = −Σ_α (E_α − μ_α N_α)/T_α（`skinheat.ness.entropy_production`）が定義できる。L=40, K_lead=10, K_b=10, W_b=4。

**結果**
1. **非相反比は浴状態 (T_b, μ_b) に厳密に依存しない。** δQ_f, δQ_r はリード分布への線形応答なので浴の寄与は差分で厳密に相殺する（テストで 1e-9）。
   κ=0.05/0.1/0.2/0.3 で ln 比 = 3.64/7.21/14.23/21.2、T_b∈{0.25,0.5,1,2} と μ_b∈{0,…,−30} で同一。
   κ=0.5 は δQ_r ~ 1e-14 で倍精度の限界（nan）。
2. **浴の離散化。** メゾスコピック浴では自己エネルギーがエネルギー依存で t_±(ε) が一定でなくなるため、ln 比は広帯域 NN 則 15.65（κ=0.2）を下回る:
   K_b=10/W_b=4: 14.23、K_b=20/W_b=6: 14.68、K_b=40/W_b=6: 14.95 → 広帯域極限で NN 則に近づく。Lindblad 損失（厳密に広帯域）は 15.652。
3. **エントロピー収支は閉じる。** 全配置で σ ≥ 0、全リザーバ同温（T_b=T_c、iso）で σ = 0（1e-8）。
   T_b = T_c のとき σ_iso = 0 なので σ_f がそのまま「整流過程のエントロピー生成」: σ_f = 0.042/0.044/0.047/0.049/0.052（κ=0.05…0.5）と κ にほぼ依らない一方、δQ_f は 1.64e-2 → 2.87e-3 に減る。
   → **整流熱あたりのエントロピーコスト σ_f/δQ_f = 2.6/4.0/7.0/10.4/18.1 は κ ∝ 1/ξ にほぼ比例して増える**（図 c、T_b=0.5）。
   コストの実体はホットリードからバルク浴への熱流 Q_bulk,f = 0.026 → 0.049（図 d）で、δQ_f/Q_bulk,f = 0.63 → 0.06。
   T_b ≠ T_c では σ_iso ≠ 0（浴‐リード間熱流）で、σ_f − σ_iso は負にもなる（図 c の T_b ≥ 1）— ΔT 応答としてのコスト指標は T_b=T_c でのみ素直。
   （観察: σ_f(T_b=T_c) と σ_f(T_b=T_h) が 4 桁一致。未解析。）
4. **粒子シンク（μ_b → −∞）は熱力学的に高価。** 同じ ln 比を保ったまま σ_f は μ_b=0: 0.047 → −1: 0.34 → −4: 3.2 → −30: 25.5（∝ |μ_b| N_bulk/T_b）と発散し、密度は 0.5 → 0.10 に落ちる（図 e、スキン的な端の盛り上がりは μ_b<0 でのみ現れる）。
   **論文のメッセージ: スキン整流は μ_b=0 の有限温度浴で半充填のまま動作し、追加の粒子流を要しない。**

**含意（論文用）**
- 第1段階の「シンクを含む収支が未定義」は解消。非相反性（t_± の構造）は浴の *散逸核* だけで決まり、浴の *占有*（T_b, μ_b）は熱力学コストだけを決める、という分離が明確。
- 整流 vs コストのトレードオフは「R → 1 には L/ξ ≳ 3 が必要、そのとき σ_f/δQ_f ∝ 1/ξ」として定量化できる。

## 2c. MPS 精度の改善（`scripts/analyze_chi.py`, `results/chi_convergence.png`, `beyond_nn.json["chi_convergence"|"dt_convergence"]`）

目的: κ=0.05, L=16/20 の ln(δQ_f/δQ_r) の誤差（χ=128, dt=0.1 で V=0 の Gauss 比 −0.11〜−0.15）を下げる。試したこと:

1. **厳密な摂動応答法**（`LindbladResponse`）: ρ_t − ρ_b = ∫₀^∞ e^{L_t s}(L_t − L_b)ρ_b ds を MPS で直接積分（基準 NESS 1 本＋摂動発展 2 本、線形化なし）。
   小系（N≤14）では Gauss の dE/dt と一致し誤差 1–2 %だが、N=32–40 では摂動状態 χ(s) の打ち切りが相対的に大きく（過渡ピークで 20–40 % 過小）、
   さらに減衰しない数値床（+3e-5）が積分に効き、V=0 で −10 %。同じ χ では引き算法より不利 → **不採用**（コードは残置）。
2. **χ 系列**（64/96/128, SVD, dt=0.1, V=0）: δQ_f のバイアス +15.5 % → +4.9 % → +0.2 %（L=16）と収束。δQ_r は +8〜17 % で χ に依らない。
3. **dt 系列**（χ=128, SVD; 0.1/0.05/0.025）: δQ_r のバイアスは dt とともに単調に減少（L=16 V=0: +16.8 % → +7.7 % → +2.6 %、ln 比 1.347 → 1.412 → 1.462、Gauss 1.500）。
   絶対電流の誤差 e(t) は t≳40 で平坦化し、その値は dt² 則に従わず「dt に線形な成分 ＋ dt に依らない（むしろ dt→小で増える）打ち切り成分 ~1e-3」。
   dt に線形外挿すると L=16 V=0: ln=1.513（Gauss 1.500, δQ_r −2.4 %）。
4. 基準状態の初期値を Gauss NESS の占有数にして緩和時間を短縮（既定化）。

**現時点の精度**: κ=0.05, χ=128, dt=0.025（＋線形外挿）で ln 比の誤差は ≈±0.02〜0.04（従来 ±0.12〜0.15 から 3–5 倍改善）。残差は χ=128 の打ち切り（絶対電流で ~1e-3、差分で部分相殺）。
これ以上は χ≥256（SVD 圧縮で 8 倍のコスト、本機では 1 run 1 日超）が必要。

# 第4段階 — 乱れに対する頑健性（`results/disorder.json`, `.png`, `scripts/run_disorder.py`, `tests/test_disorder.py`, `chain_heff_bonds`）

設定: Gauss 広帯域リード（Γ=1, W=4）、φ=π/2、T_h=1, T_c=0.5、L=40（L 依存は 10–80）、各点 60–100 サンプル。

**厳密な主張（三重対角恒等式の帰結、テストで 1e-14）**
1. **オンサイト乱れ ε_j（任意の分布・強さ）に対して T_RL(ε)/T_LR(ε)、δQ_f/δQ_r、R は厳密に不変。** G_{L1}/G_{1L} = Π_j t₋,j/t₊,j は対角要素を含まないため。
2. **ボンド乱れ（κ_j, φ_j が各ボンドで異なる）では ln(δQ_f/δQ_r) = 2 Σ_j ln|t₋,j/t₊,j|（和則）が厳密**（オンサイト乱れ同時存在でも）。
   → 整流指数はボンドごとの独立な寄与の和 = 自己平均量（揺らぎ ∝ √L、相対揺らぎ → 0）。

**数値結果**
- (a) オンサイト乱れ: R は W_d によらず一定（κ=0.05: 0.9604、0.1: 0.9992、0.2: 1.0000）。一方スループット δQ_f の中央値は Anderson 局在で崩壊:
  κ=0.1 で W_d=0/0.5/1/2/3/4 → 1.62e-2/1.26e-2/6.1e-3/5.1e-4/1.4e-5/1.6e-7（10–90 % 幅は W_d=2 で 2e-4〜1.2e-3）。
  「有用な整流窓」は δQ_f ≳ 1e-3 で W_d ≲ 1.5–2（κ=0.05–0.2）。
- (b) 順方向の L 減衰率 −d⟨ln δQ_f⟩/dL（L=10→80）: W_d=1: κ=0 で 0.020、κ=0.05 で 0.034、κ=0.2 で 0.044；W_d=0.5: 0.006/0.017/0.027；W_d=2: 0.055/0.090/0.107。
  弱乱れでは損失由来の減衰（κ=0.2, W_d→0 で ≈0.027/site）と Anderson 減衰がほぼ加算的、強乱れでは超加算的。**順方向にも「スキン効果による非局在化」は現れない**（スキン効果は順逆の比を決めるが順方向の絶対透過は損失＋局在で減る）。
- (c) ボンド乱れ（κ_j = 0.1(1 ± 0.8u)）: 平均は清浄値と一致（L=40: 7.85 vs 7.81）、std = 0.43/0.55/0.88（L=20/40/80）∝ √L。
  位相乱れ（φ_j = π/2 ± 1 rad）: 平均が ⟨sin φ⟩ = sin1 ≈ 0.84 倍（L=40: 6.56 vs 7.81×0.84 = 6.57 ✓）、std 小（0.19）。
  **ランダムキラリティ**（φ_j = ±π/2 等確率）: 平均 ≈ 0、std = 0.91/1.34/1.77 ∝ √L → 整流方向はサンプルごとにランダム、|ln r| ~ 0.1√(2(L−1))。
- (d) NNN t₂=0.3 ＋オンサイト乱れ（κ=0.2）: 恒等式が破れ、ln 比は W_d=0.5/1/2 で 10.12±0.11 / 9.71±0.19 / 9.42±0.30（清浄 10.31）とサンプル依存になるが、平均の低下は緩やか。

**含意（論文用）**
- 「整流比はスキン局在長だけで決まる」という第1段階の法則は、オンサイト乱れに対して *厳密に* 頑健（Anderson 局在と無関係）。実験的にはスループットの確保（W_d ≲ 2J）だけが課題。
- ボンド乱れでは指数が和則で自己平均 → 大きな系ほど相対揺らぎが小さい。キラリティの符号乱れだけが整流を壊す（巻き数の符号が揺らぐ）。
- 乱れ下でも R が変わらないことは、非相反性が「輸送の位相的・構造的性質（三重対角＝一次元最近接）」に由来し、固有状態の局在/非局在とは独立であることを示す。

**追記（第3段階の未解析点の解決）: σ_f(T_b=T_c) = σ_f(T_b=T_h) は厳密な恒等式。**
全リザーバが熱的なら Landauer 多端子形式で Q_α = ∫dε/2π ε Σ_β T_{αβ}(f_α − f_β)。
T_b=T_c（L 以外すべて T_c）では σ = Q_L^out (1/T_c − 1/T_h) = (1/T_c − 1/T_h)∫ ε (f_h − f_c)[1 − R_LL(ε)]、
T_b=T_h（R 以外すべて T_h）では σ = (−Q_R)(1/T_c − 1/T_h) = (1/T_c − 1/T_h)∫ ε (f_h − f_c)[1 − R_RR(ε)]（和則 Σ_β T_{αβ} = Σ_β T_{βα} = 1 − R_αα を使用）。
よって等式 ⇔ R_LL(ε) = R_RR(ε)。一様なキラル鎖では鏡映 P が h_eff を転置に写す（P h_eff P = h_eff^T: 鏡映は t₊↔t₋ を入れ替え、転置も同じ）ので
G_LL = (P G P)_11 = (G^T)_11 = G_11 → 端の反射率が厳密に等しい。φ, κ, t₂ に依らず成立し、一般のオンサイト乱れでは破れ、鏡映対称な乱れでは回復する
（数値: 清浄 φ=π/2, π/3 で差 1e-12、乱れで 3e-3、鏡映対称乱れで 1e-12; `test_thermal_bulk.py::test_sigma_mirror_transpose_identity`）。
物理的には「ホットリードが放出する熱（他が全て冷）＝コールドリードが吸収する熱（他が全て熱）」で、非相反性（G_{L1} ≠ G_{1L}）は反射には現れない、という主張。

# 論文準備メモ（穴埋め）

## 実験提案の段落（草稿、本文 1 段落＋Supplemental）

ボンド損失 L_j = √κ (c_j + e^{iφ} c_{j+1}) は、隣接 2 サイトを共通の強散逸補助モード a_j（減衰率 Γ_a ≫ g）に g(c_j† a_j + e^{iφ} c_{j+1}† a_j + h.c.) で結合し a_j を断熱消去すると得られる（κ = 4g²/Γ_a、位相 φ は結合位相）。
これは Song–Yao–Wang の「キラル減衰」模型 [Song, Yao, Wang, PRL 123, 170401 (2019)] と同じ散逸子で、Liouvillian スキン効果 [Haga, Nakagawa, Hamazaki, Ueda, PRL 127, 070402 (2021); arXiv:2005.00824] の標準的な実装法。
- **冷却原子**: 運動量格子／光格子で非エルミートスキン効果は観測済み [Liang, Xie, Dong, Li, Li, Gadway, Yi, Yan, PRL 129, 070401 (2022)「Dynamic signatures of non-Hermitian skin effect and topology in ultracold atoms」; 運動量格子の散逸 Aharonov–Bohm 鎖、確認済み]。
  J = 2π×0.5 kHz として κ/J = 0.05–0.2 → κ = 2π×25–100 Hz（補助状態へのラマン結合＋光散乱損失で可）。R > 0.99 に必要な L/ξ ≳ 3（ξ ≈ J/κ）は κ/J=0.2 で L ≈ 15 サイト、0.05 で L ≈ 60 サイト。
  熱リードは両端を大きな原子リザーバに接続する二端子輸送配置（Esslinger 型）で、温度差は蒸発冷却で設定。測定量は両リザーバの原子数・エネルギーの時間変化（ΔT 応答 δQ_f, δQ_r）。
- **超伝導回路**: トランズモン／共振器アレイ（J = 2π×10–50 MHz）で、隣接 2 素子に結合した低 Q 補助共振器（Γ_a ~ 2π×10 MHz, g ~ 2π×1–3 MHz）で κ = 2π×0.5–2 MHz。
  熱リードは両端の伝送線路に異なる雑音温度（20–300 mK）の熱雑音を注入する。ここでの担体は光子（ボソン）だが、**整流比の法則は単粒子 Green 関数の恒等式なので統計に依らず**（Fermi 分布を Bose 分布に置き換えるだけ）、純粋損失なら安定。 超伝導回路での非エルミートスキン効果の観測は、多モードパラメトリック空洞でのボソン的 Kitaev 鎖（エルミート Hamiltonian だが直交位相の動力学行列が非エルミート）[Busnaina et al., Nat. Commun. 15, 3065 (2024)] と、ポストセレクションで非相反模型を模擬したディジタル量子プロセッサ [Shen, Chen, Yang, Lee, Nat. Commun. 16, 1340 (2025)] に限られ、**散逸工学による Liouvillian スキン効果の超伝導回路実験は 2026-10 時点で未報告**（検索範囲: Web、perspective arXiv:2603.13526 の文献 [51]）。本提案はこれを熱輸送で実現する初の具体案として位置づける。関連: 光子メッシュ格子での Liouvillian 領域のスキン動力学観測 [Yang, Sun, Hong, Yang, arXiv:2606.27043 (2026)]。
- 乱れ耐性（第4段階）により、サイトエネルギーの不均一（冷却原子の光格子不整、回路の周波数ばらつき）は整流比に影響せず、必要なのは J に対して W_d ≲ 2 のスループット条件だけ。
- 差別化に使う先行研究: 熱伝導の「拡散スキン効果」[Cao, Li, Peng, Qi, Huang, Li, Zhu, Commun. Phys. 4, 230 (2021), doi:10.1038/s42005-021-00731-z; 確認済み] は古典拡散のメタマテリアル、cascaded 系の非相反熱輸送 [arXiv:1806.01000] は少数モード、非相反系の透過理論 [Ghaemi-Dizicheh & Schomerus, arXiv:2104.02905] は反射・透過の両立条件を扱うが熱整流比の厳密則は与えていない。

### 有限温度浴＋相互作用（gain_ratio=1、L=12、χ=256、dt=0.05、tag `_gain1_chi256_dt0.05`）

| 浴 | V=0 ln 比 (Gauss 2.202) | V=2 ln 比 | V=2 オフセット（vs V=0 MPS） |
