## B. 式の再導出（著者が手で追う）

各項目は「確認すること」と「数値での裏付け（テスト）」の組。テストは `make test` で全部走る。

1. **有効行列 Eq. (4)**: L_j = √κ(c_j + e^{iφ}c_{j+1}) から M_l を作り、h_eff = h − (i/2)M_l^T の (j, j+1) 要素が −J − (iκ/2)e^{iφ}、(j+1, j) 要素が −J − (iκ/2)e^{−iφ}、対角が −iκ（両端は −iκ/2）になることを 3 サイトで手計算する。φ=π/2 で −J ∓ κ/2 の実非対称ホッピングになることも確認。
   - 裏付け: `tests/test_brute_force.py`（Lyapunov 解 = 全 Fock 空間の Lindblad 定常解、10⁻⁸）。
2. **三重対角恒等式 Eq. (9)–(10) と厳密則 Eq. (11)**: L=3 の三重対角行列で (A⁻¹)₃₁ と (A⁻¹)₁₃ を余因子で書き、比が a₂₁a₃₂ / a₁₂a₂₃ になること、対角要素が比に現れないことを確認する。次に「T_RL/T_LR が ε に依らない定数なら熱平均の比も同じ定数」を Eq. (8) で確認する。
   - 裏付け: `tests/test_exact_law.py`（10⁻⁸）、`number-check.md` の III B の行。
3. **同キラリティ利得（III C）**: G_j = √(κg)(c_j† + e^{−iφ}c_{j+1}†) の M_g が M_l^T と同じ行列要素を持ち、κ → κ(1+g) になることを 2 サイトで確認。
4. **非 Bloch 形 Eq. (12)–(13)**: ψ_j = β^j を h_eff ψ = εψ のバルク行に代入して Eq. (12) を得る。t₂=0 で 2 次方程式になり β₁β₂ = t₋/t₊（Vieta）で Eq. (11) に戻ることを確認。Eq. (13) の「+O(1)」は数値で最大 2–4（`number-check.md` の IV の info 行）であり、本文は漸近形として述べている点に注意。
   - PBC スペクトル Eq. (14): Im E(k) = −κ(1 − sin k) ≤ 0 を確認（実軸巻き数 0 の根拠）。
5. **浴状態への非依存（VI B）**: δQ_f, δQ_r がリード分布の差 f_h − f_c に線形で、浴の項が Eq. (6) の引き算で消えることを多端子 Landauer 形で確認。
   - 裏付け: `tests/test_thermal_bulk.py::test_thermal_bulk_bath`。
6. **鏡映恒等式 Eq. (17)–(18)**: 鏡映 P が t₊ ↔ t₋ を入れ替え、転置も同じ入れ替えをすること（P h_eff P = h_eff^T）、したがって G_LL = G_11 を確認。和則 Σ_β T_αβ = 1 − R_αα を使って Eq. (18) を導く。
   - 裏付け: `tests/test_thermal_bulk.py::test_sigma_mirror_transpose_identity`。
7. **和則 Eq. (19)**: Eq. (10) の積をボンド依存の t_{±,j} で書き直すだけであることを確認。
   - 裏付け: `tests/test_disorder.py`。
8. **超フェルミオン写像（V A）**: 規則 cρ → c、ρc† → −c̃、ρc → c̃†、ρc_i†c_j → c̃_j†c̃_i を 1 モードの ρ = diag(1−n, n) で確認。
   - 裏付け: `tests/test_tebd_vs_gauss.py`（4 モード・V=0.7 で厳密一致、V=0 で Gauss 解と一致）。
