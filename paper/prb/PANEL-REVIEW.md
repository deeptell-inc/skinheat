## 2. 1 名の再現に基づく指摘（他の 2 名は未検証、反証もなし）

- **B-N1**: V C「相互作用は両方の応答を減らす、逆方向は少なめ」は純粋損失の χ=256 run と合わない。δQ_r は不変か増加（ln で +0.009, +0.106, +0.045）。Δ_V はほぼ順方向の減少。
- **B**: Δ_V は κ=0.05 で χ に対して未収束（χ=128: −0.20〜−0.35、χ=256: −0.42）。本文「L=16, 20 とも −0.42」は L=20 で −0.43。浴の V=0 バイアスは +0.002（本文 +0.001）。
- **B**: κ=0.2 の run は χ=64・dt=0.1・変分圧縮（本文に記載なし）、V=0 スループットが 4 %/14 % 高い、測定 δQ_r が 3 点で負（「下限」にならない）。
- **B**: 図 3 の誤差棒 0.02（κ=0.05）は本文の作り方では 0.011。0.06, 0.04 は make_figures.py に直書き。「25–35 %」は描いた 4 系列の範囲で、全データでは 19–53 %。
- **B**: 鏡映恒等式の乱れの数値 3×10⁻⁴ は 1 シード。12 シードで中央値 9×10⁻⁴、範囲 9×10⁻⁵〜3×10⁻³。「任意の t₂」は数値未確認。「全リザーバ同温で σ=0」は μ も等しいことが必要。表 III「ほぼ加法的」は W_d=2J で 37–40 % 超過。K=160 では広帯域との差 2–9 %（K=80 より悪い）。図 4(c) は 100 サンプル。
- **A**: 巻き数は ε = −2t₂ で未定義、w(−iκ) = −1 は t₂ < J のみ。熱平均は「ξ(ε)⁻¹ の Fermi 窓平均」ではなく、透過で重み付けした指数の平均の対数。Ė_α の向きが式 (6) と式 (15) で逆。
- **A**: 離散浴で γ = d を保つと自己エネルギーにリップルが残り（κ=0.2 で 0.0917〜0.1090）、K_b を増やすだけでは広帯域値に点ごとには収束しない。
- **C**: V=2J は閉鎖系・半充填・零温度の XXZ 臨界点 Δ=1。A の限定: V n n は粒子正孔対称でなく、μ=0 の開放系が半充填とは限らない（L=12 で基底状態は 5 粒子）。結論が「相関絶縁体」を未解決とするなら、この位置づけを明記すべき。
- **C**: 冷却原子の表は Γ_a, g に数値がない。引用した二端子リザーバはフェルミオン、運動量格子はボソン凝縮で空間的リザーバがない。
